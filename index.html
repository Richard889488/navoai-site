Workflow

How NavoAI finishes a complex task

Complex requests are planned, executed, repaired when needed, and finally verified against the requested output path.

01 Plan

Break the request into executable steps and list the target artifact.

02 Execute

Use direct runtime actions such as `image_generate`, `office`, `table`, `browser_task`, and `computer`.

03 Repair

If AI returns a weak plan, deterministic fallback workflows complete the required artifact anyway.

04 Verify

NavoAI checks the saved file path and remembers the result for later runs.
